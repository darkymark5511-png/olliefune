# Fune (olliefune)

Fake iPhone-style web phone · horror ARG nested device · calculator & climb game.

## Setup

```bash
npm install
cp .env.example .env.local
# set ADMIN_PASSWORD
npm run dev
```

## Vercel

- Domain: `olliefune.vercel.app`
- Env: `ADMIN_PASSWORD` (Production + Preview)

Wrong admin password → 24h ban cookie.
